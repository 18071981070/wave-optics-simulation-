# 波动光学交互式仿真平台

基于 Python + Streamlit 开发的波动光学教学与虚拟仿真实验平台。平台以“原理公式 - 参数调节 - 仪器图像联动 - 数据证据”为实验主线，支持学生自主探究与教师课堂演示。

## 功能特点

- **六类实验**：双缝干涉、单缝衍射、多缝光栅、迈克耳孙干涉、薄膜干涉、偏振干涉
- **定量互动**：参数变化同步更新仪器状态、强度曲线、观察屏图样和特征量
- **科学模型**：采用标量衍射、部分相干理论、薄膜反射相位和琼斯矩阵模型
- **教学闭环**：支持预测、测量证据、结论记录、分层任务和教师课堂脚本
- **真实观察**：使用波长对应的单色光图样，提供理论暗纹、主极大等特征标注

## 使用端与模式

1. **学生学习端**：自由实验、教学指导和分层练习
2. **教师教学端**：课堂目标、演示脚本、探究任务和课堂评价记录

## 快速开始

### 方法一：使用启动脚本（推荐）

双击运行 `run_simulation.bat` 文件

### 方法二：命令行启动

```bash
pip install -r requirements.txt
streamlit run wave_optics_simulation.py
```

然后在浏览器中打开 http://localhost:8501

## 核心参数

### 双缝干涉
- 波长、缝距、单缝宽度、屏距、相干性

### 单缝衍射
- 波长、缝宽、屏距

### 多缝光栅
- 波长、光栅常数、缝数、缝宽、屏距

### 迈克耳孙干涉
- 波长、镜面移动距离、两束光强度比

### 薄膜干涉
- 波长、膜厚、薄膜折射率、基底折射率、干涉类型

### 偏振干涉
- 波长、起偏器角度、检偏器角度、波片角度、波片类型

## 物理公式

### 双缝干涉
Δx ≈ λD/d，I = Ienv[1 + γcosδ]/2

### 单缝衍射
第一暗纹条件: a·sinθ = λ

### 多缝光栅
光栅方程: d·sinθ = kλ

### 迈克耳孙干涉
条纹移动数: ΔN = 2Δd/λ

### 薄膜干涉
δ = 4πndcosθ/λ + Δφr

### 偏振干涉
Eout = R(θ)J(δ)R(-θ)Ein
